Frequently Asked Questions

Click a question to expand the answer.

How do I connect GitHub?

Go to the GitHub page in the sidebar, click Connect GitHub, authorise the GitHub App, and select which repositories to include. You are redirected back automatically and events start flowing on your next push.

Why aren't my commits showing up?

GitHub: Check that GitHub shows Active in the sidebar and the app was running when you pushed. GitLab: Open the GitLab page and click Sync Webhooks — if webhooks weren't registered, no events will arrive. Then make a test push. Commits made while the app was offline or before connecting won't backfill automatically.

What is the green "Live" dot in the top bar?

It indicates an active WebSocket connection. New events appear in the chart and timeline automatically without a page refresh. It reconnects automatically if the connection drops.

How does the AI summary work and what does it cost?

Clicking Generate sends your activity events to GPT-4o which writes a plain-text summary. A typical daily summary (5–20 events) costs under $0.01. A heavy day with 200+ events costs around $0.03.

Can I view activity from past weeks?

Yes. On connector pages, click Pick Week ▾ and choose any past week from the calendar. On My Day use the left arrow to step back day by day. On Digest use the week arrows.

How do I generate a summary for a past day?

Navigate to that date in My Day using the arrows. If the day has events a Generate button appears — click it to create an AI summary for that exact day. The button is hidden when a day has no recorded events.

What can Ask AI answer?

Questions about your own recorded activity — "How many commits this week?", "What Jira tickets did I update last Thursday?". It understands natural time phrases. It cannot fetch live data from GitHub or Jira directly and cannot see events from days the app was offline.

Why is Teams not showing my messages?

Teams connects via your Microsoft SSO login. If messages don't appear, sign out and back in to refresh the token. Only messages you send are captured — not messages from other participants.

Does the app store my code or message content?

No. Only event metadata is stored — commit titles, file names, timestamps, event types, repository names. Full code diffs and full message bodies are never stored.

How do I switch between light and dark mode?

Use the Light / System / Dark buttons at the bottom of the left sidebar, or click your avatar in the top-right corner. The preference is saved in your browser.

GH

Connect GitHub

One-time setup. The app installs a GitHub App and registers a webhook — every future push, PR, or review appears within seconds.

Steps

  1. 1Sign in with your Microsoft account on the login page.
  2. 2Click GitHub in the left sidebar under Connectors.
  3. 3Click Connect GitHub. You are redirected to GitHub.
  4. 4Choose the account or organisation. Select All repositories or specific ones, then click Install.
  5. 5GitHub redirects you back. The page shows Active and events appear on your next push.

What gets captured

Commits — title, SHA, changed file names, timestamp
Pushes — branch name, commit count
Pull Requests — opened, merged, closed
Not stored — code diffs, full file contents
Permissions

read:org · read:user · repo — read-only. The app never writes to your repositories.

GL

Connect GitLab

Connects via OAuth 2.0. After you authorise, the app automatically registers webhooks on every GitLab project you belong to so commits, merge requests, issues, comments, pipelines, and tag pushes arrive in real time.

Steps

  1. 1Click GitLab in the left sidebar under Connectors.
  2. 2Click Connect GitLab. You are redirected to GitLab's OAuth page.
  3. 3Sign in to GitLab if prompted, then click Authorize.
  4. 4You are redirected back. The app registers webhooks on all your projects in the background.
  5. 5GitLab page shows ● Connected. Events start flowing on your next push, MR, or issue action.

→ Sync Webhooks button re-registers on all projects without reconnecting — useful if you join new projects later.

→ Disconnect removes the integration and all stored webhook links. You can reconnect any time.

→ Webhooks are registered per-project. If you have a GitLab Premium/Ultimate account, group-level hooks are tried first (covering all projects in a group at once).

What gets captured

Commits — one event per commit: message, SHA, changed file names
Merge Requests — opened, merged, closed, and updated
Issues — opened, closed, and updated
Comments — notes you add on MRs, issues, commits, or snippets
Pipelines — pipeline status changes (running, passed, failed)
Tag Pushes — new tags created on any project
Not stored — code diffs, full file contents, MR descriptions
OAuth scope required

api · read_user
The api scope is needed to register webhooks (a write operation on your projects). The app never pushes code or modifies your project content.

JR

Connect Jira

Connects via Atlassian OAuth. Ticket updates and comments appear in your feed as you work in Jira.

Steps

  1. 1Click Jira in the sidebar under Connectors.
  2. 2Click Connect Jira. You are redirected to Atlassian OAuth.
  3. 3Select the Jira site to connect (if you have multiple), then click Accept.
  4. 4You are redirected back. The Jira page shows Active.

What gets captured

Ticket Updates — status changes, field edits, transitions
Comments — comments you add to tickets
Not stored — ticket descriptions, attachments
Permissions

read:jira-work · read:jira-user · manage:jira-webhook

MS

Connect Microsoft Teams

Teams connects automatically when you sign in with Microsoft — no extra steps. The app registers a Graph subscription in the background.

How it works

  1. 1Sign in with your Microsoft account. Teams is connected at login automatically.
  2. 2The app registers a Microsoft Graph subscription in the background within a few seconds of first login.
  3. 3Messages you send appear in the feed within seconds. The subscription auto-renews.
  4. 4If Teams shows Disconnected, sign out and back in to refresh the Microsoft token.

What gets captured

Messages you send — in chats and channels
Meetings — meetings you attend
Not captured — messages from others, full message body
No Connect button needed

Unlike GitHub and GitLab, Teams connects automatically through your Microsoft SSO login — no separate OAuth flow.
